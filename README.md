## LOVE U MOM

Projeto desenvolvido durante minha participação na primeira edição do Hackathon do Servidor dos programadores.

### Tema: Dia das Mães

### O projeto:

Uma plataforma web que utiliza inteligência artificial para criar cartões personalizados de Dia das Mães. O usuário descreve a mãe,  decora o cartão da forma que quer, cria um avatar personalizado opcionalmente e a IA faz uma mensagem linda para a mãe, juntando tudo isso o cartão poderá ser salvo em pdf para ser enviado para a mamãe.

Obs: Uma seção extra de criar o avatar personalizado da mãe para adicionar no cartão (pulável).
